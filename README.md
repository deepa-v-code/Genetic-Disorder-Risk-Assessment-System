# Explainable Genetic Disorder Risk Assessment System

**Primary algorithm:** Decision Tree Classifier  
**Stack:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Flask, Streamlit

## Important scope and safety notice

This repository is an academic machine-learning demonstration built with a **synthetic dataset**.
It is not a clinically validated model, does not estimate real patient risk, and must not be used
for diagnosis, screening, treatment, or healthcare decisions. The category labels are generated
from artificial rules for software demonstration only. Do not enter real patient information.

## Project objectives

- Clean data and handle missing/invalid values.
- Perform exploratory analysis.
- Encode categorical variables and select/tune tree parameters.
- Train a Decision Tree classifier.
- Visualize the tree and feature importance.
- Evaluate training and testing performance and discuss overfitting.
- Serialize the trained pipeline.
- Expose a Flask prediction API and a Streamlit frontend.


This creates:
- `models/decision_tree_pipeline.joblib`
- `reports/model_metrics.json`
- `reports/feature_importance.csv`
- `reports/decision_tree.png`
- `reports/feature_importance.png`

## Evaluate

```bash
python src/evaluation.py
```

The training script uses a stratified 75/25 train/test split and GridSearchCV on the training
portion. It tunes `max_depth`, `min_samples_leaf`, and `ccp_alpha` to control tree complexity.
Compare training and test scores. A high training score paired with a much lower test score
suggests overfitting; prefer pruning/regularization and cross-validation rather than simply
increasing tree complexity. Also inspect precision, recall, F1-score, and the confusion matrix.

## Dataset description

`dataset/genetic_disorder_synthetic.csv` contains 1,200 artificially generated rows.
Input features include age, gender, family history, consanguinity, a simulated genetic-test
result, symptom categories, and other synthetic indicators. The target is `Disorder_Category`.
Some missing values and invalid age values are deliberately included to demonstrate cleaning.

## Limitations

- The dataset is synthetic and does not represent real genetic or clinical data.
- Labels are generated by artificial rules and are not medically meaningful.
- Model accuracy on this dataset says nothing about performance on real people.
- Feature importance is model-specific and is not evidence of causation.
- The API is a local academic demo, not production-secure software.
